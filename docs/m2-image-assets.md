# M2 本地图片素材

生成方式：内置 image_gen 工具。全部为 AI 演示素材，不是真实门店、供应商或厂家产品照片；备件图按名称对应单品，不提供适配认证。

产品采用简约白底商品摄影风格，无植物、树叶或场景装饰。仓库、供应商采用摄影风格的实际业务场景，两个仓库及三家供应商使用独立图片。横幅仅在正中40%—60%范围左右过渡，外围不加渐变。

图片目录：`frontend/public/images/`。备件通过 `image_key` 绑定，未知或未配置图片显示“暂无图片”。不使用分类组合图替代具体备件。当前支持选择本地素材，未实现任意文件上传。
