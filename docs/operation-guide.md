# 角色与日常业务操作说明

适用版本：2026-10-27，单门店、多仓库。管理员、库管、经理共享同一业务数据库；相同筛选条件下库存、流水、资料、采购和毛利查询相同，差异在操作权限及本人事项范围。

## 权限

| 工作 | 管理员 | 库管 | 经理 |
| --- | --- | --- | --- |
| 查询库存、流水、单据、统计、毛利 | 可以 | 可以 | 可以 |
| 新增/修改/停用备件、供应商、仓库 | 可以 | 不可以 | 不可以 |
| 维护供应商供货价 | 可以 | 不可以 | 不可以 |
| 维护门店定价 | 可以 | 不可以 | 可以 |
| 创建采购、领用、调拨草稿 | 可以 | 可以 | 不可以 |
| 确认采购、实收、领用过账、调拨收发 | 可以 | 可以 | 不可以 |
| 提交本人采购/调拨审核 | 可以 | 可以 | 不可以 |
| 审核他人采购/调拨 | 可以 | 不可以 | 可以 |
| 上传本地知识资料 | 可以 | 可以 | 可以 |
| 审核知识资料入库 | 可以 | 不可以 | 不可以 |
| 账号权限与操作审计 | 可以 | 不可以 | 不可以 |

采购、调拨禁止业务自审；管理员本人制单也要由其他管理员或经理审核。库管审核中心只显示本人创建的单据；普通用户只查看本人上传记录，管理员可查看全部上传。智能助手沿用当前登录人的权限，聊天里自称经理、指定另一个operator_id或回复“已批准”均不改变身份和权限。

## 采购与入库

1. 采购管理→新建采购单，选择业务仓库与日期。每条明细先选供应商，再选其有效报价覆盖的备件，填写件数。
2. 系统自动显示只读供货价、明细金额与合计。缺少报价时由管理员在备件资料维护，不用0元代替。保存草稿不增加库存。
3. 前往审核中心，由创建人提交审核，其他管理员或经理核对数量、报价、用途与仓库后通过或驳回。审核不增加库存，也不自动确认采购。
4. 管理员或库管在单据详情确认采购，再登记每次实际合格接收数。允许分次收货，累计实收不得超出采购数量。
5. 部分收货后仍可继续登记余量；全部实收后状态为已完成。每次入库单可从采购详情回查。

报价和门店售价保存为单据快照，之后维护新价格不会改写原草稿或已生效记录。草稿需采用新报价时取消重建，不能在确认后静默替换。

## 调拨与领用

调拨选择不同的来源仓与目标仓，保存草稿并按采购同样的独立审核流程处理。发出时扣来源仓、增加目标方向在途；目标仓实际整单收货后，在途转为目标仓现有量。首版整单收发，不支持部分调拨、发出后撤回或按少货情况直接全收。现有加调拨在途在纯调拨中守恒。

领用出库先选择仓库、备件、数量及维修用途。收费维修按门店定价生成结算快照；质保维修结算为0，必须填写质保说明。草稿不减库存，过账才核对可用量并扣减。此流程没有额外的采购/调拨独立审核按钮，人工核对与确认仍须完成。已过账单据不提供直接删除、撤销或重做期初抵消。

库存统一按件计数，一件为一个SKU完整包装；整瓶、整桶、整套写入名称或规格，不将包装内升数或个数混入数量。当前没有预留流程，可用量等于现有量，外部质检隔离信息仍须人工核验。

## 毛利与资料

毛利分析按已过账领用的业务日期统计。收费毛利＝收费结算－对应实际出库成本；质保成本独列；扣质保后的备件贡献＝收费毛利－质保成本。库存成本来自实际入库及移动加权分摊，调拨携带成本，不用当前供货价或门店售价替代历史成本。未包含人工、房租、税额拆分或厂家赔付，不能称净利润。

智能助手→本地知识库→上传记录，可上传UTF-8 TXT/MD、文字型PDF或DOCX，每份10MB以内。待审与驳回资料不进入检索。管理员在审核中心预览原文并审核入库，索引成功后才能被助手引用；失败显示错误并允许重试。审核入库表示本地参考资格，不代表正式企业发布或厂家认证。扫描资料暂不支持OCR。

## 智能助手

可查询库存、单据、供货报价、领用消耗和实际毛利；可检索制度和通用故障资料，按开启状态使用Tavily公开搜索；可整理采购、领用和调拨相关待确认提案。描述应给出仓库、备件、件数、业务日期及必要用途，缺少条件时补充，不要求模型猜测。

提案先展示具体参数，核对后使用“核对并确认”按钮。确认只执行卡片列明的动作；“创建草稿”不会继续自动采购确认、入库或领用过账。采购与调拨草稿仍须独立业务审核。重复确认不会重复创建或扣减；参数、价格、库存或状态变化时原提案可能失效，应重新核对，不能沿用不匹配的批准。

库存不足时可选择核查其他仓、准备缺口采购或调整需求。助手先问员工选择，不擅自缩量、拆单、换供应商或创建替代单据。通用故障回答给出可能类型、检查条件及逐件换件状态，图片和目录SKU不证明具体车型适配；症状或报码不等于必须更换。

登录令牌有效期1小时，页面刷新或失效后需重新登录；已保存的业务、会话和待确认提案可恢复，提案仍受自身30分钟有效期限制。查询失败显示持续错误与重试入口，不把失败当作零库存。

接口机器说明见 `api/openapi-20261027.json`，运行中的交互文档为 `http://127.0.0.1:8000/docs`。常用路径：`/api/documents`、`/api/reviews/documents`、`/api/inventory/balances`、`/api/profits`、`/api/knowledge/submissions`、`/api/assistant/threads`。写请求使用唯一request_id，同一标识与不同参数会冲突；服务端鉴权、事务和幂等不能由前端按钮替代。
