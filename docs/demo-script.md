# 实际操作演示路线

本脚本使用明确的项目模拟数据，不代表真实供应商下单、付款或正式门店审批。日常演示先准备允许写入的演示/测试环境；不要为演示重置已有开发库。2026-10-27的验收样例已清理，具体单据号仅用于报告追溯。

| 时长 | 操作 | 需要展示的结果 |
| --- | --- | --- |
| 1分钟 | 管理员、库管、经理分别登录，使用相同筛选查询库存 | 库存相同；账号/审计、新增、执行与审核入口按权限不同 |
| 2分钟 | 库管新建采购，逐行选择供应商→备件→数量 | 自动带出供货价与合计；草稿待提交审核，现有量不变 |
| 1分钟 | 创建人提交，其他管理员或经理审核 | 自审/库管审核拒绝；审核后仍由经办人员确认采购 |
| 1分钟 | 分两次收货 | 部分收货→已完成，分别生成实收入库单，余额和待收同步更新 |
| 1分钟 | 调拨草稿审核后发出、收货 | 来源减少、在途单列、目标实收增加，数量与价值守恒 |
| 1分钟 | 各办理一笔收费和质保领用 | 收费使用门店价、质保为0且有说明，过账才扣库存 |
| 1分钟 | 打开毛利分析并追溯单据 | 收费毛利、质保成本、贡献分列；成本来自实际入库，不是当前报价 |
| 2分钟 | 库管上传一份带可核验独有条款的MD；管理员预览审核 | 待审不可检索，入库后回答能引用真实行号；经理/库管审核被拒绝 |
| 2分钟 | 助手查询、缺货追问与创建采购提案 | 使用实时工具；员工选择后才整理方案；人工按钮确认生成草稿，可跳转查看，仍待独立审核 |
| 1分钟 | 身份边界和通用故障问题 | 自称管理员/指定operator_id不切换身份；无检测时不认定必换或目录适配；资料说明与实时查询范围明确 |

验收数值示例：开场两仓账面合计16件、价值5800元；采购4件×400元并分两次实收后20件、价值7400元。调拨3件只改变位置，不产生收入。目标仓收费领用2件、质保领用1件后全仓17件、价值6310元。收费结算1100元、收费成本726.67元、收费毛利373.33元、质保成本363.33元、扣质保贡献10.00元。数值仅适用于本轮固定样例，不能套到现有48类备件的开发库。

展示的失败应保留：缺货不能自动出库、未审批不能发出、经理不能登记库存、他人不能确认会话提案。不要将业务草稿生成说成已向供应商实际下单，不把本轮少量用例称为模型准确率。
