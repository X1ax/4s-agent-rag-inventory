## 最小修改

仅修改 `backend/app/retrieval.py` 的库存 hybrid 非精确条款路径，检索版本记为 `hybrid-tfidf-rrf-context-v2`。

1. 保留原 RRF Top-5 原始命中，先完成原父章节及原显式引用扩展。
2. 在 dense/lexical 各自最多20条候选中，分别取前 `top_k` 个不同父章节作为补充候选。
3. 已存在的章节不重复加入；其他章节整段加入，标记 `branch_candidate_section`，仍受原预算与本次允许文档范围限制。
4. dense、故障域、精确条款编号请求不走该补充分支。来源撤回、文档版本过滤及请求结束时的资格复核继续由原机制执行。

没有更换 Embedding、修改原文、放宽文档资格、引入新依赖或增加每次请求的 Embedding/对话模型调用次数；索引仍为原代次，无需重建。平均库存固定题上下文由 3586.3 增至 5556.8 字符，约增加55%，这是实际代价，不能声称没有 token 或延迟影响。没有相同条件下的对话耗时对比，不推导性能提升。

只按父章节去重替换 Top-5 的试验使扩展覆盖达到63/71，但直接命中由49降至39；父章节融合、全列表融合及正文 BM25 试验也未得到可接受的整体结果。这些探索只在只读诊断脚本中运行，未并入生产。最终采用保留全部原证据后的有限补充，不按题号或预期条款强制命中。
