# 双价格、实际库存成本与备件毛利统计设计

状态：用户已批准并已实施，财务定向验收通过；完整回归仍有既有Chroma间歇失败，详见 `docs/pricing-gross-profit-verification.md`。日期：2026-10-26。

## 已确定的目标

用户要求保留供应商确定的供货价与4S店定价，普通员工不能改供货价；出库时选择收费维修或质保维修；基于实际入库成本统计毛利，不计人工、房租等经营费用。用户进一步要求确定价格后补齐历史缺失部分。保留现有多Agent、人工审核/确认、权限与幂等业务流程，不提交Git。

这里的“实际”指根据系统中已过账入库成交价计算，而非用当前报价估算；项目既有业务及新增补录仍为模拟数据，不宣称是真实门店经营结果。

## 当前事实与改动范围

只读核验开发库：48类备件、96条仓库余额（73条正库存）、373件现有库存、1张在途调拨5件。19条期初明细共201件，没有成本字段。227张已过账入库单379条明细均有非零采购价格；403张已过账出库单958条明细共1810件均未记录收费/质保与结算价。出库现有unit_price=0是旧结构约束，不能解释成全部免费。

`Part.reference_price`目前混用采购参考价，`Supplier`只有类别供货范围，没有逐备件报价。`documents.change_stock`只处理数量；页面与Agent共用`create_document/receive_purchase/transition`；统计入口为`business_api.statistics`。沿用这些模块，在共享业务事务内加入计价，不新增另一套库存写入流程或通用财务引擎。

## 方案比较与建议

当前报价乘出库量只能估算，已被用户排除。先进先出可以反映实际采购成本，但需要采购成本层及逐次分摊；本项目没有批次管理，首版增加这些结构收益有限。建议采用按“仓库＋备件”的永续移动加权平均成本，匹配已有余额粒度；跨仓调拨携带来源成本进入目标仓平均。这是本设计提出的实现选择。

## 价格与权限

1. 供应商供货价按供应商＋备件唯一保存，包含报价、来源说明、更新时间、版本和启用状态；没有报价与合法0元报价分别表示。供应类别和逐件有效报价都满足才可采购。
2. 门店定价保存在备件，新增独立`sale_price`，不把原参考价改名成售价。原`reference_price`作为兼容采购参考字段保留，但新采购不再以它代替供应商报价。
3. 采购明细保存所选供应商报价版本及金额快照，服务端决定价格，员工和Agent伪造单价会被拒绝。已保存采购单沿用其价格快照，不因后续报价修改而重写；发生议价时由管理员先依据报价更新记录，再重新制单。当前采购单不实现逐行随意改价或折扣。
4. 新建出库必须明确整单用途`paid_repair`或`warranty`，同单不混合收费/质保。收费时服务端带出门店定价并冻结到草稿；质保结算为0且填写质保说明，可选填工单编号，不要求引入工单系统。零售价表示未定价，收费出库不能静默按0结算。确认后不得改价；草稿需改用途/价格时取消重建，保持已有单据策略。
5. 建议权限：管理员依据供应商报价维护供货价和基础资料；管理员、经理只通过独立接口维护门店定价；库管查询价格、办理库存业务，无价格维护权。经理不会因此获得其他主数据修改或库存登记权限。改价记录前后值、来源、操作人、时间。相关只读数据现阶段沿用已登录用户可见规则，不另加财务角色。
6. Agent能查双价格和成本统计、整理采购及收费/质保出库提案；不得自行设置价格、成本或报价。用途未明确必须追问，不能替员工决定收费/质保。所有提案包含价格版本/用途快照，价格或关键业务条件变化时重新确认，不悄悄重价。已有采购/调拨业务审核规则保持。

## 成本与金额规则

金额使用Decimal与定点字段，单价最多2位小数，库存价值/出库成本金额精确到分；中间运算使用至少40位精度，按ROUND_HALF_UP取分。平均单价可展示6位，但以库存总价值为账本，不用展示后单价反乘。

```text
入库金额 = 本次合格实收数量 × 已保存采购单价
入库后数量 = 原数量 + 实收数量
入库后价值 = 原库存价值 + 入库金额
出库成本 = round(出库前价值 × 出库数量 / 出库前数量, 2)
出库后价值 = 原价值 - 出库成本
```

全数出库取全部剩余价值，避免分摊尾差；数量为0时价值必须为0。缺少成本用NULL与明确原因表示，不能默认为免费。新期初登记必须提供单位成本；正常系统只在确认存在免费来源且有说明时接受0成本。

采购创建、审核、确认、取消未收部分均不影响库存价值；实际入库才增加。部分收货只按实收数量入账。收费/质保出库过账时保存实际分摊成本，不在草稿阶段扣成本。后续调价、采购或补录不重算已完成新单据。

调拨发出同时扣来源数量和价值，将成本金额固定到该调拨明细；收货按同一金额进入目标仓，不使用目标仓当前均价或供应商新报价。发送后收货前该金额为在途成本，不能同时算作来源或目标现有价值。纯调拨须同时满足数量及价值（含在途）守恒，不产生收入或毛利。

成本顺序采用实际过账顺序，在稳定库存行锁内计算，不按可回填的业务日期反复重算。报表按流水过账业务日期筛选，并说明成本依据实际执行顺序；补录旧业务日期不触发自动改写后续成本。每次数量、价值、成本快照、流水、单据状态、审计、幂等结果在原事务内提交。

## 数据结构与接口范围

- 新增供应商备件报价记录，唯一关系、报价来源及版本；缩小供货类别使范围外报价不可用于新采购，历史快照不变。
- 备件新增门店售价及价格版本；余额新增可空库存总价值；期初明细新增单位成本和成本来源。
- 出库单新增用途/质保说明及工单参考；单据明细新增报价/门店价格版本、结算价快照、实际出库或调拨成本金额。库存流水新增价值变动，独立于现有采购`unit_price`字段，避免改写旧语义。
- 使用一份版本化补录计划及执行记录保存历史新字段的前后值、模拟来源、规则种子、数量与流水指纹；必要的改价/成本初始化记录是独立审计事实，不改变数量流水。
- 新增报价维护、售价维护、毛利只读查询；现有采购/出库接口扩展明确字段与校验。前端、接口和Agent共享校验与统计，不向模型开放SQL或成本编辑。
- 可增加一个小型确定性成本计算模块供共享库存流程使用，不创建成本策略插件、抽象仓储或事件总线，不新增运行依赖。

## 历史补齐（用户已要求）

先形成可审阅的固定种子计划，再显式运行；不在启动或迁移时随机改数据。旧采购/入库单价、业务日期、数量、操作者、审核记录、库存余额数量和流水数量全部保留。

1. 报价计划：为现有合格供应商—备件生成明确标记的模拟供货价，以既有参考价及既有采购价为价格锚点，固定种子形成可解释的供应商差异；生成独立门店售价。既有未来新增的人工定价/报价不被脚本覆盖。
2. 期初成本：19条缺失期初成本按既有同备件最早入库价为锚点；无记录时按已登记模拟供货价生成，标记“模拟期初成本补录”及规则来源。不是实际历史凭证，不改原期初数量和日期。
3. 历史出库：403单按单据固定随机种子分配收费维修/质保，建议整体约85%/15%，各备件比例自然波动，不给每个备件复制完全相同记录。生成标记的历史门店结算价格，不能声称取自旧系统。旧单据`unit_price=0`原值保留，新结算字段独立保存；出库价与当前门店定价变动分别表达。
4. 按库存流水ID的真实过账序列重放：期初补录价值、已保存实收成交价、出库分摊及调拨成本传递共同推导现有/在途价值。不得按业务日期重新排列到导致当时负库存的顺序。重放的每个余额数量必须与当前库一致，否则整体不执行。
5. 重放只补齐新增成本/用途/结算字段及其来源，不新增伪造的库存收发事件。历史模拟毛利结果单独可识别；不把当前门店价格套用于所有过去日期。所有导出/图表保留模拟补录口径说明。
6. 运行前备份目标字段与基线数量校验摘要；执行时停止相关业务写入，在数据库锁与事务中复核计划指纹、行数、价格和数量。参数/基线变化则拒绝，不自动重生成计划。相同版本重复执行不重复补录或累计金额。
7. 首次补录包括那张5件在途调拨：发送成本重放后固定，今后收货必须携带同一金额。已有未完成采购按原采购价继续。旧未过账出库草稿无用途时必须先补用途或取消重建；旧待确认Agent提案标记失效并要求重生成，不删除会话或已执行结果。

模拟定价规则的建议默认值：固定种子20261026，以SKU/供应商编码/单据ID等稳定业务标识生成独立随机序列，不能依赖Python随机hash。供应商报价以现有备件参考价为锚点，默认供应商沿用该数值，其他合格供应商报价在95%—105%间变化；门店定价按默认供货价的1.25—1.60倍生成SKU固定系数，均取分。历史收费结算以补录计划中的同SKU价格锚点及固定加价系数为基础，每个自然月生成97%—103%的固定价格变动，同SKU同月保持一致，不逐单无缘由随机调价。质保比例通过单据独立随机序列约15%产生，补录完整后报告实际比例，不硬改成完全相等。所有规则、候选具体价格与成本逐行写入待执行计划，用户审阅/管理员维护后冻结，之后脚本不能覆盖人工修改。比例与候选价格均属于项目模拟定价，不宣称来自市场调查。

## 毛利口径与页面

```text
收费维修结算金额 = 已过账收费出库结算价 × 数量
收费维修成本 = 对应已保存实际出库成本之和
收费维修毛利 = 收费维修结算金额 - 收费维修成本
收费维修毛利率 = 毛利 / 收费维修结算金额（分母0时显示暂无）
质保消耗成本 = 已过账质保出库成本之和
扣除质保后的备件贡献 = 收费维修毛利 - 质保消耗成本
```

不计人工、房租等经营费用；不叫净利润。不把质保按门店定价虚构收入，也不把质保成本重复扣进收费毛利。暂不涉及厂家赔付、税额拆分、付款/开票、运费分摊、折扣、退库退款、负库存或成本层管理。统一按系统记录的每件成交金额管理，页面说明金额范围而不声称财务报表。

独立毛利分析区域复用仓库、备件分类、备件、日期筛选；包括收费结算金额、收费成本、收费毛利、质保成本；备件毛利排行（可选毛利额/率/数量、分页7条）、时间趋势、收费/质保占比和可追溯明细。仓库为空表示全仓汇总，毛利率以汇总金额计算，不能平均各行比例。未知成本/用途的记录显示缺失数量与未覆盖金额，不静默排除再宣称全量。

备件资料展示门店定价和供应商供货价（多家展开）；采购价格只读、显示报价来源；出库选择用途、收费显示价和结算金额、质保显示0结算与说明。成本展示以实际成本状态为准，不用当前报价替代。全部原有选择控件支持清除，错误提示持续可见。
