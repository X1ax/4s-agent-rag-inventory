# 全仓全备件单一统计区验收

日期：2026-10-23。此文件记录先前多单位兼容方案。随后用户要求统一单位为件，现已取消多单位并列；最终口径与验证见 `unit-normalization-verification.md`。未进入M3.4，未提交Git。

## 最终交互与口径

仓库不选表示全部仓库，备件不选表示全部备件。初次进入不强制选中第一个备件，“更新统计”可直接使用；清除备件或仓库会重新查询对应全部范围。指定备件时继续使用其实际单位。

页面只保留三个指标卡、一张趋势图、一份排行和一份低库存列表。指标卡内按单位并列列出现有、采购待收和调拨在途数量；不同单位不相加，不生成缺乏业务含义的总数量。

趋势改为按业务日期统计采购入库单和已过账领用单张数。一张单据包含多种备件或单位时只计一张，期初和调拨不计入；选择具体备件后只统计包含该备件的单据。现有量仍为当前快照，不受趋势日期筛选改变。

备件排行按领用单据数降序，同频次按备件 ID 稳定排序，最多10种；每项同时显示领用频次、实际数量和单位。进度条按频次计算，不比较不同单位的数量。低库存合并各单位结果，每项保留自身单位。

后端 `/api/statistics` 未传 unit 和 part_id 时返回按单位分开的 groups，同时返回去重的 activity_trend 和包含 unit/issue_count 的 consumption_ranking。指定单位或备件时保留原单单位 totals 等字段；旧数量趋势保留供已有接口使用，页面明确使用单据趋势。无需数据库迁移。
