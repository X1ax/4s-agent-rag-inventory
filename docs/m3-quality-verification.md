| 缺口 | 实际处理及验证 |

| 数值题过度追问或直接让模型计算 | 保留逐字输入来源、整数和单位校验；支持方向明确的仓库别称、字段与数值绑定、分配输入等价结构、制度默认顺序及同句共用“各N件”。结果统一由确定性分支复算，缺条件仍追问 |
| 检测记录被误降级 | 明确用户转述的本日完整检查记录可以作为当前提供的证据；观察必须在逐字记录中，判据必须来自记录或实际引用手册；假设检查方案不当作已完成检测。不补造测试结果、通用阈值或实际商品适配 |
| 正文与部件状态不一致 | 不重复输出模型正文中的换件结论；未满足证据条件的类型降为证据不足，缺症状引用的候选单独剔除，保留其他有依据的安全分流；拒绝和范围外状态不被空候选改写 |
| 结构输出失败 | condition允许空并由服务端显示一般限制；仅允许补齐JSON末尾唯一缺失的对象闭括号，未结束字符串、缺失值及其他损坏仍报错，不拼造事实 |

| Chroma间歇性向量段读取错误 | 实际复现`Error creating hnsw segment reader: Nothing found on disk`。数量和元数据校验不代表向量段可读。构建批量与落盘阈值均设16，构建指纹包含该配置；构建及重开校验实际读取向量并执行查询，失败不发布代次。未用自动重试隐藏异常 |
