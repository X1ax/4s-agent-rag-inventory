## 本地文档上传与审核

入口为“智能助手 → 本地知识库 → 上传与审核”。已登录用户可以提交资料，普通用户只能查看自己的提交，管理员查看所有提交并审核。前端不能通过修改角色字段取得审核权限；审核接口使用服务端administrator依赖。

支持UTF-8 TXT/Markdown、文字型PDF和DOCX，每份最大10MB；PDF限100页，不支持加密PDF与OCR。DOCX限制解压体积与条目数，不接受宏文件。单段/单页超过3200字符、总文本超过20万字符或300片段会明确提示拆分，不能静默截断条件。解析结果供审核预览，待审核原件不会出现在RAG来源清单中。

| 状态 | 行为与检索资格 |
| --- | --- |
| pending | 待审核，仅上传人及管理员可查看记录；不进入RAG |
| rejected | 审核未通过；不进入RAG，修改后重新上传 |
| approved | 已保存审核记录，正在准备/建立索引；尚不显示入库成功 |
| index_failed | 索引失败，回退已审核来源清单；可重试，未取得新资料检索资格 |
| indexed | 审核与索引完成，进入默认本地参考资料范围 |

审核保存管理员ID、意见和时间。原件、解析预览与审核SQLite记录在`data/knowledge/uploads`，只将审核通过的原件哈希、片段与定位登记到`approved.json`，然后使用既有独占索引机制重建。构建失败保留旧索引并回退来源登记；查询执行期间再次核对来源，避免资格变化后的旧回答继续返回。索引更新期间返回明确维护状态，普通库存业务不依赖此索引。

上传资料使用`UPL-<uuid>`来源编号，TXT/MD保留行号，PDF保留真实页码，DOCX保留正文块与表格序号。审核入库属于本地参考资料资格，不代表企业正式发布、OEM认证或具体商品适配。默认参考范围可检索，正式发布范围不把它视为正式制度。当前不提供已入库资料撤回、替换版本或批量审核；管理员不能用待审操作撤回已入库资料。

## 本地资料配图

管理员新增/编辑备件、仓库或供应商时，可以从本机选择PNG/JPEG/WebP静态图片，限制5MB及1600万像素。服务端验证实际内容、方向和帧数，重新编码PNG并移除原文件名与元数据；使用39字符的`upload-<uuid>`键，沿用现有image_key字段，不新增迁移。保存资料前可预览、清除或改选内置图。图片写入`data/uploads/images`，预览通过固定图片端点提供，与内置目录图一样供本机页面展示，不接受任意URL或路径。清除引用不删除文件，当前无自动孤立文件回收。

## 业务异常与专业措辞

增加只读`assess_request`，复用既有业务提案快照与原业务约束，不另写库存扣减逻辑。库存不足返回所需、可用和缺口，提供核查跨仓调拨、准备缺口采购、调整原需求三个路径；供应范围不符、停用资料、单据状态冲突、超量/错误收货明细、提案过期与快照变化也返回可核对事实和处理选项。

选项只填入输入框，不自动发送或执行业务。本轮发现业务异常后禁止自动改变原参数生成替代提案；员工在下一轮选择方案后重新核对与补齐条件。仍由人工按钮确认具体提案，采购草稿不等于外部下单或实际入库。暂不支持部分调拨收货，不能以部分实物到达办理整单收货。具体可调数量须引用确定性补货工具，不以安全库存替代目标量。

界面与新回答使用“人工审核”等措辞，旧会话展示时兼容替换旧口语标签，不改写用户原话或来源原文。目录工具支持数字ID检索；库存快照明确Asia/Shanghai与+08:00。

## RAG修复与版本

库存术语INV-GLO-011-C006统一包装件口径，文档升级至1.0-draft.2，旧资料、manifest和固定输入归档在`evals/inventory/archive/quality-before-20261025`。当前源哈希、评测引用版本及corpus-lock同步；历史运行文件不覆盖，重复使用旧验收题只能作为已暴露回归。

假设调拨允许从明确方向绑定A仓/B仓，仍校验数值原文；默认分配顺序采用制度的余量降序、编码升序、所列需求顺序，用户指定其他顺序不能静默覆盖。完整30日领用量的纯假设计算可显式声明已过账口径假设，不能冒充真实业务历史。实际补货工具仍要求完整历史来源。

故障recommended要求可定位的逐字检测记录，不通过时降为undetermined，避免降级卡片仍保留重复换件正文。conditional要求用户原文的已知检查条件或明确假设检查方案。库存制度输出夹带故障字段时返回outside_scope空结论；部件只引用公共规则、无对应症状证据时返回insufficient_evidence空结论，不伪造部件引用。仍保留无效证据ID与未知部件键的拒绝校验。
