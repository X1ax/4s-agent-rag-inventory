# M3.5 智能助手、引用问答与联网搜索验收

日期：2026-10-24。未提交Git。当前阶段完成不等于M3.6固定评测或M4业务Agent完成。

## 本轮最终范围

用户在开发中将单次问答页调整为类似ChatGPT的连续聊天界面，名称为“智能助手”。提供新会话、历史消息、上下文追问、底部输入框、Enter发送、Shift+Enter换行、处理状态、持续错误及显式重试。自动判断库存制度/故障资料，不要求逐次选择知识域。引用按消息保存，可展开正文与原生定位。

用户明确选择默认使用项目参考资料，且不设置外部专业人员复核前置门槛。助手默认draft_preview；界面显示“项目编制资料”，不反复要求核准。原始清单保留历史编制元数据，没有伪造正式批准人、日期或厂家身份。低层knowledge API仍默认released_only，当前正式发布范围为空。

按新增要求接入Tavily公开搜索。公开网页和项目资料分别标记；只提供固定/search接口、最多5条摘要、单次10秒、无自动重试，不下载全文或执行网页指令。明显凭据、邮箱、手机号、VIN等搜索词拦截不代表完整脱敏系统。

首页新增“办理调拨”入口。库存关注同时覆盖低于安全库存与零库存，去重后分页12项；安全阈值为0的新增目录也能在零库存中看到，未建账/未设阈值分别标明。用户最后取消了关注区域独立仓库筛选，仅保留页面顶部已有仓库筛选。

## 后端与边界

新增只读知识接口：status、documents、retrieve、ask、chunks；复用current_user。Pydantic拒绝越权字段、路径和非法枚举；响应不包含服务器绝对路径或配置凭据。

后端生命周期持有同一index_owner锁。仅单进程访问索引；缺索引、被占用或配置不兼容时，普通业务health/ready不变，知识功能单独报不可用。离线构建/导出/切换和索引CLI查询前须停止该后端。只检查来源的parse_knowledge --check-only不初始化索引，可并行运行。

引用绑定代次与实际提供片段。模型不能自造引用或部件类型；MD/TXT使用章节/行，PDF真实页，DOCX正文块与表格上下文。生成结束再次核对来源，期间撤回或变更则丢弃回答；旧代次或来源失效的引用返回409。

四类纯假设计算为补货、调拨守恒、完整自然日、给定顺序分配。参数须有用户原文出处，整数/Fraction与ceil复算；不查询业务库存或建单。连续对话仅在有限历史用户消息中复用假设与检查线索，历史助手回答不作为数值来源；出处存在不等于参数语义或检测记录真实性已经自动认证。

故障输出区分undetermined/not_indicated/conditional/recommended。推荐更换需给出可定位的用户检查记录和对应症状条目引用；缺少则降为条件判断。类型图来自既有白名单，不说明实物适配、实际需求或库存充足。

Chat Completions、Embedding和Tavily分别使用独立配置。DeepSeek官方接口用非思考JSON模式；其他兼容服务不擅自添加该供应商参数。总请求截止45秒，Embedding/搜索10秒、单次对话30秒；前端50秒，普通业务仍15秒。对话意图判断与资料回答最多两次模型请求，整个流水线共用45秒。

## 会话持久化

会话保存于已忽略的data/assistant.sqlite3，与MySQL业务事务分开。按服务端用户ID核对所有权；其他账号不能枚举、读取或追加消息。保存用户消息、公开回答、引用与失败状态，不保存模型内部思考或密钥。

相同会话/请求标识的完成结果直接复用，不重复调用模型；不同内容冲突。每会话只允许一轮处理中，失败可显式重试最后一轮；重启后将未完成轮次标记中断。此幂等仅用于聊天，不冒充采购/调拨业务幂等。上下文仅使用最近6轮已完成消息，尚无长期摘要和无限上下文。

## 本轮交互与主数据追加验收

最终名称为“智能助手”。输入区仅保留一个可点击“本地知识库”入口，去除右上角重复项；入口与推荐问题悬停/键盘聚焦为#0071e3。浏览器读到推荐问题hover=true且计算色rgb(0,113,227)。欢迎文案为“查询信息、梳理业务，让日常工作更高效”，不突出单项故障诊断；发送按钮仅“发送”且居中。

会话右键菜单同时提供“重命名会话 / 删除会话”，支持Shift+F10和Esc。PATCH /api/assistant/threads/{id}接受非空1—80字符标题；DELETE同路径删除本人会话与消息，处理中返回409。跨账号请求404。删除前界面确认，浏览器验收取消了删除，没有删除用户已有会话；隔离SQLite测试验证实际删除和无孤立消息。浏览器实际将本轮生成的合成VARTA查询会话改名“VARTA 官方资料查询”，再次打开仍能读取原消息。
